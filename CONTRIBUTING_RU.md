# Вклад в проект

Репозиторий предназначен для контролируемой разработки CryptoHunter Neural Scalper.

## Перед изменением

1. Создайте отдельную ветку.
2. Сформулируйте измеримую цель.
3. Определите, затрагивает ли изменение данные, модель, исполнение или риск.
4. Сделайте backup `var/`.

## Имена веток

```text
feature/<краткое-название>
fix/<краткое-название>
docs/<краткое-название>
experiment/<краткое-название>
```

## Обязательные проверки

```bash
python -m compileall -q src tests integration
python -m pytest -q
node --check src/neuroscalper/web/static/app.js
```

## Требования к PR

- объяснить проблему;
- описать решение;
- перечислить изменённые контракты;
- приложить тесты;
- описать риск и rollback;
- приложить метрики, если меняется модель/стратегия;
- приложить скриншоты, если меняется UI;
- обновить документацию.

## Запрещено коммитить

- API keys и `.env`;
- `.venv`;
- пользовательский `var/`;
- необработанные большие датасеты;
- неизвестные бинарные checkpoint;
- сторонний код без фиксации происхождения;
- обход risk manager;
- включённую реальную торговлю по умолчанию.

Подробности: `docs/DEVELOPER_GUIDE_RU.md`.
