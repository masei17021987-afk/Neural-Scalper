# Быстрый старт

## Ubuntu — рекомендуемый сценарий

### Однократная установка

```bash
cd ~/CryptoHunter-Neural-Scalper
chmod +x INSTALL_UBUNTU.sh
./INSTALL_UBUNTU.sh
```

После этого программа запускается из меню приложений Ubuntu по значку **CryptoHunter Neural Scalper**.

### Запуск из терминала

```bash
./start.sh
```

### Остановка

```bash
./STOP.sh
```

### Публикация на GitHub

```bash
./PUBLISH_TO_GITHUB.sh
```

Откроется официальная браузерная авторизация GitHub, затем будет создан приватный репозиторий.

Полная Ubuntu-инструкция: [UBUNTU_RU.md](UBUNTU_RU.md).

## Windows

1. Установите Python 3.11 или 3.12 с галочкой **Add Python to PATH**.
2. Распакуйте архив.
3. Дважды нажмите `START.bat`.
4. В открывшемся браузере нажмите **Запустить демо**.

## Что нажать в первый день

1. **Главная → Запустить демо**.
2. **Бэктест → Синтетический рынок → 6 000 событий**.
3. **Нейросеть → Синтетические данные → 6 000 примеров**.
4. После обучения снова запустите демо и проверьте статус модели.
5. **Рынок и данные → Подключить данные** для записи реального стакана.

Синтетический тест проверяет механику, но не доказывает прибыльность.

## Частые проблемы Ubuntu

### Python или venv не найден

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip
```

### Браузер не открылся

Откройте вручную:

```text
http://127.0.0.1:8094
```

### Порт занят

```bash
./STOP.sh
NEUROSCALPER_PORT=8095 ./start.sh
```

### CUDA недоступна

```bash
nvidia-smi
./CHECK_GPU.sh
```

Программа продолжит работать на CPU.

### Binance не подключается

Демо работает без Binance. Проверьте интернет, доступ к доменам Binance и страницу **Журнал**. После разрыва программа должна переподключиться и заново восстановить стакан.
