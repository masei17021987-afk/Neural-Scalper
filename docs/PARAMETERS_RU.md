# Все параметры

## Рынок

| Параметр | Что означает | Безопасный старт |
|---|---|---:|
| `symbol` | анализируемый бессрочный USDT-контракт | `BTCUSDT` |
| `depth_levels` | число уровней bid и ask в модели | `20` |
| `update_ms` | частота depth-потока | `100` |
| `record_raw_events` | сохранять snapshots | включено |
| `record_features` | сохранять рассчитанные признаки | включено |
| `stale_after_ms` | порог плохой задержки для quality monitor | `1500` |

## Модель

| Параметр | Влияние | Безопасный старт |
|---|---|---:|
| `sequence_length` | сколько последних состояний видит модель | `64` |
| `hidden_size` | размер GRU и общей embedding | `96` |
| `dropout` | защита от переобучения | `0.15` |
| `min_confidence` | минимальная уверенность входа | `0.62` |
| `min_net_edge_bps` | движение после расходов | `1.2` б.п. |
| `use_gpu` | использовать CUDA при наличии | включено |
| `mixed_precision` | FP16 на GPU | включено |
| `batch_size` | размер пакета обучения | `128` |
| `epochs` | число проходов по train | `8` |
| `learning_rate` | шаг AdamW | `0.0008` |

Повышение `min_confidence` и `min_net_edge_bps` сокращает число сделок. Их снижение не создаёт преимущество, а лишь пропускает более слабые сигналы.

## Исполнение

| Параметр | Влияние | Значение |
|---|---|---:|
| `preferred_order_type` | adaptive / post_only / limit / market | `adaptive` |
| `maker_fee_bps` | комиссия лимитного входа | `2.0` |
| `taker_fee_bps` | комиссия рыночного исполнения | `5.0` |
| `assumed_latency_ms` | задержка решения и биржи | `65` |
| `queue_factor` | доля лучшего уровня перед заявкой | `0.65` |
| `cancel_after_ms` | время ожидания лимита | `900` |
| `slippage_bps` | дополнительное ухудшение цены | `0.5` |
| `max_spread_bps` | вход запрещён выше порога | `4.0` |

Для стресс-теста увеличьте комиссию, latency и slippage. Стратегия, которая исчезает после небольшого ухудшения, слишком хрупкая.

## Риск

| Параметр | Влияние | Значение |
|---|---|---:|
| `initial_balance` | старт paper-счёта | `10000` |
| `risk_per_trade_pct` | допустимая потеря по стопу | `0.25%` |
| `max_position_notional_pct` | верхний notional позиции | `10%` |
| `max_open_positions` | одновременные позиции | `1` |
| `max_daily_loss_pct` | аварийный дневной стоп | `2%` |
| `max_drawdown_pct` | стоп от high-water mark | `10%` |
| `max_consecutive_losses` | серия до усиленной паузы | `5` |
| `cooldown_seconds` | пауза после закрытия | `20` |
| `stop_loss_bps` | начальный стоп | `18` б.п. |
| `take_profit_bps` | начальная цель | `30` б.п. |
| `trailing_activation_bps` | начало trailing | `18` б.п. |
| `trailing_distance_bps` | расстояние trailing | `10` б.п. |
| `max_holding_seconds` | принудительный выход по времени | `180` |

## Стратегии

- **Импульс** — согласование короткой доходности, потока сделок, объёма и microprice.
- **Drops** — падение плюс подтверждённый reset; продолжающийся обвал штрафуется.
- **Pumps** — различает продолжение роста и истощение.
- **Liquidations** — ликвидация не является входом сама по себе; нужен ответ стакана.
- **Volume** — агрессивные сделки на нескольких окнах.
- **Spread** — качество ликвидности и цена входа.
- **Waves** — согласование движения 3/10/30 событий.

Итоговый вес модели и правил нормализуется автоматически.
