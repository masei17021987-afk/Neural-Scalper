## Обозначения

- **б.п.** — базисные пункты; 1 б.п. = 0,01%;
- **LOB** — limit order book, стакан лимитных заявок;
- **paper** — виртуальное исполнение без реального ордера;
- **recorded** — данные, записанные программой из публичного потока;
- **synthetic** — искусственно сгенерированный рынок для проверки механики;
- **fail-closed** — при сомнении вход блокируется, а не разрешается.
