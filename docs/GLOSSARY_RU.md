# Словарь терминов

| Термин | Простое объяснение |
|---|---|
| **Ask** | минимальная цена, по которой продавец готов продать |
| **Bid** | максимальная цена, по которой покупатель готов купить |
| **Best ask/bid** | ближайшие к рынку цены двух сторон стакана |
| **Spread** | разница между best ask и best bid |
| **Mid price** | середина между best bid и best ask |
| **Basis point, б.п.** | 0,01%; 10 б.п. = 0,10% |
| **LOB** | limit order book, стакан лимитных заявок |
| **L2 / MBP** | агрегированный объём на каждом ценовом уровне |
| **L3 / MBO** | отдельные заявки с идентификаторами и очередью |
| **Depth** | ликвидность на нескольких уровнях стакана |
| **Imbalance** | дисбаланс объёма bid и ask |
| **Microprice** | цена, смещённая с учётом объёмов лучших сторон |
| **Order flow** | последовательность сделок, добавлений и отмен |
| **Aggressor** | участник, который пересёк спред и забрал ликвидность |
| **Maker** | участник, чья лимитная заявка стояла в книге |
| **Taker** | участник, немедленно забравший ликвидность |
| **Fill** | исполнение заявки |
| **Partial fill** | исполнение только части объёма |
| **Queue ahead** | объём заявок, который должен исполниться перед нашей |
| **Slippage** | ухудшение цены относительно ожидаемой |
| **Latency** | задержка между событием/решением/заявкой/ответом |
| **Adverse selection** | заявка исполняется преимущественно перед движением против неё |
| **LONG** | позиция, зарабатывающая при росте |
| **SHORT** | позиция, зарабатывающая при падении |
| **FLAT** | отсутствие позиции или отказ от входа |
| **Signal** | структурированное торговое предложение системы |
| **Confidence** | уверенность модели; не вероятность гарантированной прибыли |
| **Gross edge** | прогноз движения до расходов |
| **Net edge** | прогноз после заложенных расходов |
| **Volatility** | изменчивость цены |
| **Regime** | состояние рынка: тренд, диапазон, импульс, стресс и т.п. |
| **Router** | модуль, выбирающий вес/режим поведения по состоянию рынка |
| **Baseline** | простая контрольная модель для сравнения |
| **Checkpoint** | сохранённые веса и метаданные модели |
| **Inference** | получение прогноза готовой модели |
| **Epoch** | один полный проход по train-набору |
| **Batch** | группа примеров, обрабатываемая за шаг обучения |
| **Learning rate** | величина обновления параметров модели |
| **Dropout** | регуляризация, случайно отключающая часть активаций в train |
| **Train set** | данные для оптимизации модели |
| **Validation set** | данные для выбора параметров/checkpoint |
| **Test set** | финальная отложенная проверка |
| **Walk-forward** | последовательное обучение на прошлом и тест на будущем |
| **Look-ahead bias** | использование информации из будущего |
| **Overfitting** | модель выучила историю, но не обобщает |
| **Paper-trading** | виртуальные сделки без биржевых приказов |
| **Shadow mode** | live-прогнозы без приказов с последующей сверкой |
| **Backtest** | воспроизведение стратегии на истории |
| **Event-driven** | обработка последовательных рыночных событий |
| **PnL** | прибыль/убыток |
| **Equity** | капитал с нереализованным PnL |
| **Balance** | реализованный остаток |
| **Drawdown** | снижение от предыдущего пика капитала |
| **Stop-loss** | выход при неблагоприятном движении |
| **Take-profit** | выход при достижении цели |
| **Trailing stop** | стоп, движущийся вслед за выгодной ценой |
| **Cooldown** | принудительная пауза между сделками |
| **Kill switch** | глобальная аварийная блокировка входов |
| **Fail-closed** | при неопределённости действие запрещается |
| **Reconciliation** | сверка локальных ордеров/позиций с биржей |
| **Rate limit** | ограничение числа API-запросов |
| **Funding** | периодический платёж между сторонами perpetual futures |
| **Mark price** | расчётная цена для PnL/ликвидации фьючерсов |
| **Liquidation** | принудительное закрытие маржинальной позиции |
| **OHLCV** | open/high/low/close/volume свечи |
| **JSONL** | один JSON-объект на строку |
| **WAL** | режим SQLite с журналом предварительной записи |
| **Checksum** | контрольная сумма для проверки неизменности файла |
