# Отчёт о проверке сборки 0.1.0

Дата сборки: 2 августа 2026 года.

## Автоматические проверки

Команда:

```text
PYTHONPATH=src pytest -q
```

Результат: **9 тестов пройдено, ошибок нет**.

Проверены:

- загрузка REST-снимка и последовательные обновления локального стакана;
- обнаружение разрыва sequence;
- отсутствие повторного учёта одной и той же сделки;
- crossed-book и контроль качества данных;
- high-water kill switch;
- учёт входной и выходной комиссии в PnL;
- построение исполнимых обучающих меток LONG/SHORT/FLAT;
- событийный бэктест;
- локальные HTTP API и статический интерфейс.

Дополнительно выполнены:

- `python -m compileall` для исходного кода, тестов и интеграционного шаблона;
- `node --check` для `app.js`;
- чистый smoke-запуск с пустой папкой `var`;
- запуск и остановка демо-потока через HTTP API;
- проверка, что `live_orders_enabled=false`;
- визуальная проверка всех семи страниц при ширине 1440 px;
- проверка отсутствия горизонтального переполнения и ошибок JavaScript.

## Что не выдаётся за проверенное

- Доходность не подтверждена. Синтетический бэктест проверяет механику, а не наличие торгового преимущества.
- Публичное подключение к Binance не удалось прогнать из среды сборки из-за запрета DNS-соединений. Реализация выполнена по официальной схеме REST snapshot + buffered WebSocket diff и должна быть отдельно проверена на компьютере пользователя.
- Windows `.bat`-скрипты проверены статически, но не исполнялись в Linux-среде сборки.
- Реальный order router отсутствует намеренно.
- Точная market-by-order позиция в очереди неизвестна при L2-данных; симулятор использует консервативную оценку.

## Рекомендуемый порядок приёмки

1. На Ubuntu выполнить `./INSTALL_UBUNTU.sh`, затем `./start.sh`.
2. Проверить демо в течение 10–15 минут.
3. Запустить `./RUN_TESTS.sh` (Windows: `RUN_TESTS.bat`).
4. Запустить синтетический бэктест.
5. Подключить публичные данные Binance без API-ключей.
6. Записать несколько часов данных и проверить отсутствие sequence-gap в журнале.
7. Только затем обучать модель на записанной истории.
