CRYPTOHUNTER NEURAL SCALPER 0.1.1 — НАЧНИТЕ ОТСЮДА
===================================================

UBUNTU — ОСНОВНОЙ СЦЕНАРИЙ
--------------------------
1. Распакуйте архив полностью.
2. Откройте терминал в папке проекта.
3. Выполните:

   chmod +x INSTALL_UBUNTU.sh
   ./INSTALL_UBUNTU.sh

После установки запускайте программу через меню приложений Ubuntu
или командой ./start.sh. Для остановки используйте ./STOP.sh.

Публикация проекта на GitHub:

   ./PUBLISH_TO_GITHUB.sh

WINDOWS
-------
Дважды щёлкните START.bat. Остановка — STOP.bat.

Важно: реальные ордера в этой версии отсутствуют и заблокированы.
Программа предназначена для исследования, обучения, бэктеста,
записи данных и paper-trading.
