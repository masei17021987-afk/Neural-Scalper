CRYPTOHUNTER NEURAL SCALPER — БЫСТРЫЙ СТАРТ В UBUNTU
=====================================================

РЕКОМЕНДУЕМЫЙ ФОРМАТ АРХИВА: .tar.gz
Он сохраняет права выполнения Linux-скриптов.

ПЕРВАЯ УСТАНОВКА
----------------
1. Распакуйте архив в постоянную папку, например:
   ~/Applications/CryptoHunter-Neural-Scalper

2. Откройте терминал в папке проекта и выполните:

   chmod +x INSTALL_UBUNTU.sh
   ./INSTALL_UBUNTU.sh

Сценарий установит служебные компоненты, подготовит Python 3.12,
создаст .venv, установит зависимости и добавит ярлык в меню Ubuntu.

ОБЫЧНЫЙ ЗАПУСК
--------------
Откройте в меню приложений:

   CryptoHunter Neural Scalper

Либо из папки проекта:

   ./start.sh

ОСТАНОВКА
---------
Закройте терминал сервера, нажмите Ctrl+C или выполните:

   ./STOP.sh

ПУБЛИКАЦИЯ НА GITHUB
--------------------

   ./PUBLISH_TO_GITHUB.sh

Скрипт установит официальный GitHub CLI при необходимости,
откроет авторизацию в браузере, создаст private-репозиторий
CryptoHunter-Neural-Scalper и загрузит проект без force push.
