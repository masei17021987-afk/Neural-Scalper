# Политика безопасности

## Поддерживаемая версия

На этапе 0.x исправления безопасности вносятся только в последнюю версию ветки `main`.

## Как сообщить о проблеме

Не создавайте публичный issue, если проблема может раскрыть:

- торговые ключи;
- персональные данные;
- уязвимость удалённого выполнения;
- способ обхода risk manager;
- приватную торговую логику.

Свяжитесь с владельцем репозитория через приватный канал GitHub. В сообщении укажите версию, commit, шаги воспроизведения, влияние и безопасный пример.

## Область

Особенно важны сообщения о:

- утечке secrets;
- внешнем bind без аутентификации;
- небезопасной загрузке checkpoint;
- path traversal;
- command injection в launcher scripts;
- обходе kill switch;
- повреждении paper state/SQLite;
- зависимости с критической уязвимостью.

## Текущий статус

Версия 0.1.1 не содержит live order router. HTTP API должен оставаться доступным только на `127.0.0.1`.
